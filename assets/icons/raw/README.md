# Ícones exportados manualmente do Figma

Salve aqui os SVGs/PNGs exportados do Figma (um arquivo por ícone único de carta —
papagaio, peixe, leão etc., sem duplicar os pares). Depois de salvos, avise no chat: eu
organizo em `res://assets/icons/cards/` e deixo o Godot importar.

Cores exatas (hex) podem vir só como texto no chat — não precisam de arquivo, ver
`docs/design-notes.md` para a lista de papéis de cor já mapeados a partir do print.

Este diretório é temporário/de recebimento — o conteúdo final organizado fica em
`res://assets/icons/cards/`, não aqui.
